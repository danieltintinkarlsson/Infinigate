# thumbs/

Place a screenshot of the Infinigate theme here named `original.png`.

This image is displayed as the theme preview in the FreshRSS theme selector (Admin → Appearance).

**How to capture it:**
1. Install the theme in FreshRSS (`p/themes/Infinigate/`)
2. Activate it via Admin → Appearance
3. Take a screenshot of FreshRSS with the theme active
4. Save it as `original.png` in this folder

Recommended size: 800×600 px or similar 4:3 ratio.
